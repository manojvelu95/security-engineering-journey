# Security Engineering Journey

This repository documents my journey toward becoming a Cloud Security and Application Security Engineer.

My goal is to understand:

* How systems work
* What trust assumptions they rely on
* How attackers abuse those assumptions
* How modern systems are secured
* How security engineers design resilient systems

## Learning Framework

For every topic, I explore:

1. Why does it exist?
2. How does it work?
3. What trust assumptions exist?
4. How can attackers abuse it?
5. How is it secured today?
6. What should security engineers think about?
